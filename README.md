Курсова робота з теми «Веб-сайт магазину».


 Інструкція по запуску

 Спосіб 1 (через WebStorm)
1. Відкрити проєкт у WebStorm.
2. Відкрити файл index.html.
3. Натиснути Run або відкрити через Open in Browser.

 Спосіб 2 (через браузер)
1. Завантажити або клонувати репозиторій.
2. Відкрити файл index.html у будь-якому браузері.
